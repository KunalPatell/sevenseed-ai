## 3. Windows long-path issue (real, will bite you again)

`core.longpaths` was **not enabled** for this repo. This repo has many deeply-nested paths (e.g. `sites/*/app/__next.app.__PAGE__.txt`) that exceed Windows' 260-char limit, so files silently fail to check out — `apps/sevenseed/backend/` looked like it didn't exist on disk for a while during this session even though git tracked it, which cost real time to diagnose. Fixed via:
```
git config core.longpaths true
git checkout HEAD -- .
```
This is now set for this local clone, but **won't be set on a fresh clone elsewhere** — worth adding to a setup doc/README, or setting globally with `git config --global core.longpaths true`.
