How the resolver works

score(q,t) = 0.50·prefix(q,t) + 0.30·fuzzy(q,t) + 0.20·popularity(t) prefix exact title/alias prefix hit, then whole-word containment fuzzy normalised subsequence coverage, gap-penalised miss no result above threshold → hand the raw query to the AI path generator instead of showing an empty page path reverse the DAG's `next` edges → ancestor set of the target → Kahn topological sort → ordered study sequence + hour total

The prerequisite path is a real topological sort over the same graph learn-dag.html renders, loaded from the shared data/topics.js — so the two pages can never disagree about what depends on what. Nodes you have already marked mastered on the DAG page are shown as done and excluded from the hour total.
