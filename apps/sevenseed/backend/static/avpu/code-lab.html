Challenge #04 · Deep Learning Math

Implement Scaled Dot-Product Attention

Write a Python function scaled_dot_product_attention(Q, K, V) that computes the attention scores across sequence vectors.

Formula:
Attention(Q, K, V) = Softmax( (Q · Kᵀ) / √d_k ) · V

Requirements
  • Calculate dot product between Query and Transposed Key matrices.
  • Divide by square root of Key dimension (d_k).
  • Apply softmax along the last axis so attention weights sum to 1.0.
  • Multiply attention weights by Value matrix.
