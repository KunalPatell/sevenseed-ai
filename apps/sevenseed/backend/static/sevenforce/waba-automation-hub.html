WhatsApp Workspace

Connect your own WhatsApp Business number and run it from here: a shared inbox, opt-in broadcasts with your approved templates, keyword flows, and a bot that answers only from documents you give it, handing the chat to a person when it can't. There's no platform fee. Meta bills your account directly for messages.

1 · Create your workspace

A workspace holds your connection, contacts, messages, flows and documents. Its key is kept only in this browser. Save it somewhere safe, because it's the only way back in.

2 · Connect WhatsApp

From your Meta app's WhatsApp → API Setup page. Use a permanent System User token, because the temporary one expires in 24 hours. These are stored on our server so incoming messages can be answered while you're away. Delete the workspace to remove them.

3 · Point Meta's webhook here

In your Meta app: WhatsApp → Configuration → Webhook → Edit. Paste these two values, then subscribe to the messages field. Incoming messages, delivery and read receipts will then show up in the Inbox.

This service runs on a free host that sleeps when idle. The first webhook after a quiet spell can take up to a minute while it wakes. Meta retries, so messages aren't lost, but that first reply can be slow. Without an app secret, anyone who knows the callback URL could post fake events to it, so add the secret.

Flows

A flow starts when an incoming message contains one of its keywords. Use * for a flow that catches every message no other flow matches.

Bot settings

When no flow matches, the bot searches your documents. It replies only if it finds a relevant passage and the AI can answer from it. Otherwise it sends your handoff message and flags the chat for a person.
