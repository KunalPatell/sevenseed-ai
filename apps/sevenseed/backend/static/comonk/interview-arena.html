Problem: LRU Cache Implementation

Design a data structure that follows the constraints of a Least Recently Used (LRU) Cache.

Implement the LRUCache class with get(key) and put(key, value) in O(1) average time complexity.

Input: lru = LRUCache(2) lru.put(1, 1) lru.put(2, 2) lru.get(1) # returns 1 lru.put(3, 3) # evicts key 2 lru.get(2) # returns -1 (not found)
