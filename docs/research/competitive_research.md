# Competitive Research & Feature Gap Analysis

## Learning/Education Sites
- learn-anything.xyz: Interactive knowledge graphs (DAG), topic exploration, AI-powered learning paths, fuzzy search
- freecodecamp.org: Interactive coding challenges, progress tracking, certificates, curriculum structure  
- duolingo.com: Gamification, streaks, XP, leagues, spaced repetition
- lawsofux.com: Interactive examples for UX principles, visual explanations
- 100daysofcode.com / 100daysai.com: Challenge tracking, daily streaks, community

## E-commerce/Price Comparison
- smartprix.com: Side-by-side spec comparison, ratings, price history
- buyhatke.com: Price drop alerts, historical price graphs, coupons
- xerve.in: Price comparison across stores
- google.com/shopping: Unified product search with filters

## Features to Add to Sevenseed
1. Interactive DAG/Knowledge Graph - Already have curriculum DAG but enhance with better visualization
2. Spaced Repetition System - Add review queue like Anki/Duolingo
3. Gamification - XP, streaks, achievements, leaderboards
4. Price Comparison Engine - Enhance existing price tools
5. AI-Powered Search - Fuzzy search with suggestions
6. Interactive Learning Modules - Code labs with tests
7. Progress Tracking Dashboard - Comprehensive user stats
